# 太陽系擴充到 58 個天體

branch：`feature/expanded-bodies`
參考：`work/expanded-bodies`（之後改成 `archive/expanded-bodies`）

## 目標

主遊戲的太陽系從 15 個天體擴充到 58 個：加上火衛、木衛、土衛、天衛、海衛、冥王星和它的衛星、主帶和柯伊伯帶的小天體、彗星。新天體都能在地圖上看到、選取、飛過去、降落。

## 要做的事

1. **星表只有一份**：直接用 branch 的 58 天體星表取代 `orbit/systems/sol.json`，不另外存一份。原有天體的 ID 不變（ember＝Io、rime＝Europa、hollow＝Ganymede、umber＝Callisto、haze＝Titan、selene＝Moon），新天體的 ID 是去掉標點的小寫真名。
2. **星表的來源**：產生星表用的原始資料快照和 Python 腳本是外部參考資料，放到 `ref/expanded-catalog/`，不進 git（第 6 條）。
3. **主世界的外觀和地形**：`main_game` 為每個天體都設定外觀。原本有專門設定的 10 個不變；其他天體都是有小隕石坑的球體，顏色依天體種類（冰衛星、火山的 Io、冥王星、彗星和碳質小行星、矮行星、一般岩石）。地形高度取半徑的 1%，最多 2500 m。
4. **按 O 生船**：半徑小於 1000 km 的天體，軌道高度改成半徑的 1/4，原本固定的 400 km 對小天體太遠。
5. **地圖標籤**：天體變多後，標籤依天體大小和相機縮放，位置不再因為四捨五入來回跳；Sol 和恆星用 18 px。
6. **大氣 LUT 的 bug**：小天體的大氣表反算時，最外圈的半徑可能因捨入落在大氣層外 1 ulp。改成在端點直接回傳精確的邊界值。
7. 主世界變了，所以升 `MODEL_VERSION`；舊存檔直接拒絕。

## 不做的事

- 不改積分器和誤差設定。N 體的效能另外處理，這次只量測並回報。
- 不做真實的不規則形狀、泰坦的大氣、彗星的彗髮和彗尾。

## 驗收

- 測試：新星表能建成、所有天體能生成地形和環境、存讀檔一致。
- 使用者開遊戲：地圖上能看到新天體，標籤不擠在一起、不跳動；選幾個新天體（例如 Phobos、Enceladus、Pluto、Halley）用 DEV 放船過去，看得到地形，可以降落；加速時間的速度和畫面流暢度和之前比沒有明顯變差。
